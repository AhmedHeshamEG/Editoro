# so whichever pip touches last wins. Installing plain `onnxruntime` on Windows

# nothing reports it. If that happens:
#   pip uninstall -y onnxruntime onnxruntime-gpu
#   pip install onnxruntime-gpu[cuda,cudnn]==1.22.0

# `onnxruntime` to a Windows environment.
